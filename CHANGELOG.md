### ⚡ Новые возможности и улучшения:
* **Queue Reply (`queue_reply` / NEW)**: Возможность отвечать на любые загружающиеся и отправляемые сообщения. Отображается плашка «Очередь отправки» в предпросмотре ответа; цепочка ответов выстраивается до 50 сообщений и автоматически резолвится при подтверждении сервером без потери связи.
* **Фиксированное меню реакций (`static_reactions_enabled`)**: Возможность закрепить постоянный порядок и набор любимых реакций вместо динамических недавних.
* **Умный помощник багрепортов (`smart_bug_report_helper`)**: Анимированная плашка `[ 📎 Вставить тех. информацию ]` над полем ввода при наборе сообщений об ошибках («баг», «краш», «вылетает», «ошибка»). В один клик прикрепляет диагностические данные о системе, сборке и Qt.
* **Плавающий мини-плеер Always-on-Top и Компакт**: Поддержка компактного режима (`mini_player_compact`, 380px) и закрепления поверх всех окон (`mini_player_always_on_top`).
* **Виртуальный кэш дедупликации медиа (`media_deduplication` / BETA)**: Мгновенная отправка ранее загруженных файлов по SHA-256 хэшу без повторной передачи байт на сервер и с автоматической обработкой устаревания `file_reference`.
* **Опросы в личных сообщениях (`polls_in_pm` / BETA)**: Создание опросов в 1-на-1 чатах и Избранном.
* **Режим пересылки по умолчанию (`default_forward_mode`)**: Настройка стандартного поведения при пересылке (с автором / без автора / без автора и подписи).
* **Карточки цитат текстов песен (`lyrics_quote_card` / BETA)**: Контекстное меню в плеере с быстрым копированием строки или генерацией карточки цитаты в формате Markdown.
* **Бесшовное воспроизведение аудио (`gapless_playback` / BETA)**: Фоновая предзагрузка следующего трека за 3 секунды до конца для непрерывного звучания без задержек.
* **TgWsProxy Flowseal v1.11.4**: Защита от раздутых MLKEM ClientHello TLS, защита MTU и сторожевой таймер (watchdog) родительского PID для предотвращения зависших фоновых процессов.

### 🛠️ Исправления сборки и CI:
* **Windows MSVC**: Устранён каскад ошибок `error C2440` / `error C3535` в `peer_list_box.cpp` из-за нетипизированного range-for списка инициализации rect-ов.
* **Linux Docker Buildx Cache**: Переведён на нативный GitHub Actions Buildx кэш (`type=gha,scope=docker-centos`), устранена ложная инвалидация кэша динамической директорией poetry `.venv`.
* Зарегистрированы файлы `extera_media_cache.cpp` и `extera_media_cache.h` в `CMakeLists.txt`.

## [Fork v1.0.0] — Независимый релиз от NanoDev (`nanodevmc/oxDesktop`)

### Ключевые изменения и архитектурные улучшения форка:
* **Интеграция официального API бейджей exteraGram:**
  - Полностью удалены сторонние серверы, фальшивые бэйджи "портера", принудительная очистка кэша и хардкод персональных ID автора апстрима (`metawka`).
  - Подключен официальный эндпоинт верификации профилей `https://api.exteragram.app/api/v1/profiles` и `.../profiles/updates?since={ts}`.
  - Реализовано локальное кэширование профилей в `tdata/extera_profiles.json` с поддержкой документарных ID (Developer `5359407509327085568`, Supporter `5391059537102927631`, Trusted `5452008215409629764`).
  - Очищен интерфейс профиля: удалены навязчивые попапы пожертвований и поддельные баннеры.

* **Инлайн-калькулятор и конвертер величин (порт из Android APK):**
  - Поддержка расширенных математических выражений в строке ввода: тригонометрия (`sin`, `cos`, `tan`), корни (`sqrt`), логарифмы (`log`, `ln`), округление и модули (`abs`, `round`, `floor`, `ceil`, `min`, `max`), константы (`pi`, `e`).
  - Вычисление процентов: `15% of 2500`, `1200 + 20%`, `1200 - 15%`.
  - Преобразование систем счисления: `hex 255`, `0xff to dec`, `dec to hex`.
  - Множители величин: `5k`, `2.5m`.
  - Конвертер единиц измерения (метрические и имперские): длина (`km`, `m`, `cm`, `mm`, `mi`, `yd`, `ft`, `in`), вес/масса (`kg`, `g`, `mg`, `lb`, `oz`), объем (`l`, `ml`, `gal`), температура (`C to F`, `F to C`).
  - Конвертер валют и Telegram Stars: поддержка курсов `USD`, `EUR`, `RUB`, `GBP`, `TON`, `STARS`, `XTR`.
  - Конвертер часовых поясов: текущее время и перевод времени между городами и зонами (`now in tokyo`, `18:00 utc to msk`, `6pm est`).

* **Управление форматированием и интерфейсом чата:**
  - Добавлена настройка `disable_markdown` ("Отключить Markdown-разметку"): предотвращает случайное автоматическое форматирование (`**жирный**`, `__курсив__`) при вводе технического текста или кода.
  - Добавлена настройка кнопки "Пожаловаться" (`show_report_button`) в контекстном меню сообщений (скрыта по умолчанию).
  - Добавлены гранулярные переключатели для ИИ Telegram: `telegram_ai_editor` (ИИ-редактор текста) и `telegram_ai_summaries` (краткие сводки чатов).

* **Поиск по числовому Telegram ID:**
  - В строку глобального поиска добавлена обработка чистых числовых ID пользователей, базовых групп (`-ID`) и супергрупп/каналов (`-100ID`). При поиске локально загруженные сущности мгновенно выводятся в результатах поиска.

* **Универсальное кэширование компиляции для разработчиков:**
  - Нативная поддержка `sccache` и `ccache` во всех сценариях сборки (`build_win.bat`, `build_linux.sh`, `build_mac.sh`).
  - Сохранение `.obj` / `.o` файлов между сборками ускоряет повторную компиляцию в 2–5 раз на Windows, Linux и macOS.
