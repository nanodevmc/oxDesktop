## Получение учётных данных API

Чтобы собрать вашу версию Telegram Desktop, вам необходимо предоставить собственные **api_id** и **api_hash** для доступа к Telegram API.

Как получить **api_id** и **api_hash**, описано здесь: [https://core.telegram.org/api/obtaining_api_id](https://core.telegram.org/api/obtaining_api_id)

Если вы собираете приложение не для развёртывания, а только для тестирования, вы можете использовать учётные данные **TEST ONLY**, которые очень ограничены сервером Telegram API:

**api_id**: `17349`
**api_hash**: `344583e45741c457fe1862106095a5eb`

Ваши пользователи начнут получать внутренние ошибки сервера при входе, если вы развернёте приложение с этими **api_id** и **api_hash**.
