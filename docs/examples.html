Практические примеры плагинов

Коллекция готовых шаблонов с чистым, идиоматическим Python-кодом для создания ваших расширений.

Пример 1: Однофайловый плагин (.plugin) — Математический калькулятор

Полностью автономный плагин в одном файле calc.plugin. Вычисляет выражения прямо при вводе команды .calc <выражение>:

# calc.plugin
__id__ = "calc_plugin"
__name__ = "Калькулятор"
__version__ = "1.0.0"
__author__ = "@oxDesktop"
__description__ = "Вычисление математических выражений по команде .calc"
__permissions__ = ["messages.read", "messages.send"]

import client_utils

def safe_eval(expr):
    allowed_chars = "0123456789+-*/(). "
    if all(c in allowed_chars for c in expr):
        try:
            return str(eval(expr, {"__builtins__": None}, {}))
        except Exception:
            return "Ошибка вычисления"
    return "Недопустимые символы"

@client_utils.on_send
def handle_calc(msg):
    text = msg.get("text", "")
    if text.startswith(".calc "):
        expr = text[6:].strip()
        res = safe_eval(expr)
        return {"text": f"🧮 {expr} = **{res}**"}
    return msg

Пример 2: Однофайловый плагин (.plugin) — Генератор спойлеров

Оборачивает текст в скрытый спойлер при использовании команды .sp <текст>:

# spoiler.plugin
__id__ = "spoiler_helper"
__name__ = "Генератор спойлеров"
__version__ = "1.0.0"
__author__ = "@oxDesktop"
__description__ = "Быстрое скрытие текста под спойлер командой .sp"
__permissions__ = ["messages.send"]

import client_utils

@client_utils.on_send
def handle_spoiler(msg):
    text = msg.get("text", "")
    if text.startswith(".sp "):
        secret = text[4:].strip()
        return {"text": f"||{secret}||"}
    return msg

Пример 3: Логирование в Toast при входе в личные сообщения

Показывает всплывающее уведомление при переходе в личный диалог:

# pm_toast.plugin
__id__ = "pm_toast"
__name__ = "PM Toast"
__version__ = "1.0.0"
__author__ = "@oxDesktop"
__description__ = "Уведомление при переходе в личные сообщения"
__permissions__ = ["ui", "hooks"]

import client_utils

@client_utils.on_chat_opened
def notify_pm(chat):
    if chat.get("is_user"):
        client_utils.show_toast(f"Открыт диалог с {chat.get('name')}")
