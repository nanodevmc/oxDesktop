UI-стилизация: модуль ui_hooks

Модуль ui_hooks позволяет Python-плагинам изменять форму, размеры, радиусы скругления, цвета и видимость нативных элементов интерфейса oxDesktop без правки C++ кода.

Основные функции

ui_hooks.set_style(plugin_id: str, target: str, **props) -> None

Регистрирует или обновляет переопределение стиля для указанного элемента интерфейса.

  • shape: "circle", "oval", "pill", "rounded_rect"
  • width_scale / height_scale: масштаб ширины и высоты (0.3 .. 3.0)
  • corner_radius: радиус скругления углов в пикселях
  • bg_color / border_color: HEX-цвет (например, "#181b22")
  • border_width: толщина обводки в пикселях
  • alpha: прозрачность фона (0 .. 255)
  • visible: видимость элемента (True / False)

ui_hooks.clear_style(plugin_id: str, target: str = "") -> None

Сбрасывает стиль конкретного target или все стили плагина (вызывайте в on_plugin_unload).

Поддерживаемые таргеты

  • "chat.jump_down" — кнопка прокрутки чата вниз
  • "chat.send_button" — кнопка отправки сообщения / голосовых
  • "chat.input_bar" — строка ввода сообщения в чате
  • "chat.top_bar" — верхняя шапка чата

Пример: овальные кнопки-стрелки

from base_plugin import BasePlugin
import ui_hooks

class ChatArrowsStylePlugin(BasePlugin):
    def on_plugin_load(self):
        ui_hooks.set_style(
            __id__,
            "chat.jump_down",
            shape="oval",
            width_scale=0.88,
            height_scale=1.18,
        )

    def on_plugin_unload(self):
        ui_hooks.clear_style(__id__)
